# Richmond Turnpike: Before & After

Static photo gallery, 16 before and after pairs. Deployed on Netlify from this repo.

- `index.html` is the whole site (styles and script inline).
- `images/` holds the photos, named `NN-before.jpg` and `NN-after.jpg`.
- `fetch-photos.sh` downloads any missing photos from the old Carrd page.
